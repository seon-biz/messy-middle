# 덱 디자인 템플릿 (Reveal.js 빌드 기준)

스펙이 완성된 뒤 이 문서의 토큰과 레이아웃으로 단일 HTML을 빌드한다. 이 템플릿은 확정 표준이다 — 매 빌드마다 새 디자인을 발명하지 않는다.

## 디자인 토큰

```css
:root {
  --bg: #F4F3F1;            /* 밝은 웜 그레이 배경 */
  --ink: #1A1A1A;           /* 본문·제목 */
  --accent: #C8380D;        /* 챕터 라벨·강조 (붉은 주황) */
  --muted: #8A8A8A;         /* 보조 텍스트·푸터 */
  --line: #D8D6D2;          /* 구분선·표 괘선 */
  --card: #FFFFFF;          /* 카드 배경 */
}
```

- 폰트: `Pretendard, 'Noto Sans KR', sans-serif` (CDN 로드). 제목은 800~900 굵기, 자간 -0.02em.
- 화면비 16:9 (1280×720 기준). 여백 넉넉히 — 슬라이드당 좌우 88px, 상하 64px 안팎.
- 색은 위 5개만 쓴다. 그래프·다이어그램 강조도 --accent 하나로.

## 공통 프레임

- **상단**: 좌측에 붉은 챕터 라벨(예: "진단", "채널 · 블로그") 작게 + 그 아래 가는 수평선(--line). 표지는 클라이언트명 라벨.
- **하단 푸터**: `N · [클라이언트명] · [YYYY. M.]` — --muted, 12px 안팎, 좌측 정렬.
- **하단 결론 한 줄**: 슬라이드 내용의 요지를 본문보다 약간 굵게, 푸터 위에. (대부분의 슬라이드에 존재)

## 레이아웃 유형 (스펙의 "레이아웃:" 지시와 1:1 대응)

| 유형 | 구성 |
|---|---|
| 표지 | 좌: 초대형 제목(80px+, 붙여쓰기 느낌의 좁은 자간) + 부제 / 우: 원본 보고서 커버 이미지(있을 때) 또는 여백. 하단에 클라이언트·날짜·출처 한 줄 |
| 선언 | 화면 중앙에 큰 선언 문장 1~2줄(56px+), 그 아래 --muted 보조 한 줄 |
| 카드 | 2~4장 가로 배열. 카드: 흰 배경, 라운드 12px, 옅은 그림자 없음(플랫), 상단에 작은 라벨(--accent 또는 --muted) + 큰 숫자/제목 + 본문 2~3줄 |
| 표 | 헤더 행은 --muted 소문자 느낌, 괘선은 가로선만(--line). 셀 좌측 정렬, 행 간격 넉넉히 |
| 여정/루프 | 가로 흐름: 단계 박스 + 화살표. 문제 지점은 --accent 테두리·텍스트로 강조 |
| 깔때기 | 위(넓음)→아래(좁음) 3단 블록 + 우측 점선 보조 동선. 각 단에 한 줄 설명 |
| 번호 목록 | 01 02 03… 큰 번호(--accent) + 행동 문장. 한 화면 4~5개까지 |
| 2단 비교 | 좌/우 제목 + 각 3~4줄. "지금/바꾼 뒤", "AI가 가져가는/사람이 들어오는" 등 |
| 흐름도 | 좌→우 3~4단계 박스 + 화살표. 로드맵은 단계 카드 4장(카드 유형 변형: 카드 안에 "이번 주:" 줄 포함) |

## Reveal.js 빌드 규칙

- 단일 HTML 파일. Reveal.js는 CDN(`https://cdnjs.cloudflare.com`)에서 로드.
- 슬라이드 전환은 `fade`, 속도 빠르게. 진행 표시줄·페이지 번호는 자체 푸터로 대체(Reveal 기본 번호 끄기).
- 다이어그램(루프·깔때기·흐름도)은 이미지가 아니라 HTML/CSS(flex + 의사요소 화살표) 또는 인라인 SVG로 그린다.
- 한 슬라이드에 스펙의 시각 콘텐츠만 넣는다. 설명(발표 대사)은 `<aside class="notes">`에 넣어 화면에 보이지 않게 한다.
- 표지 커버 이미지는 스킬의 `assets/decoding-decisions-cover.png`를 HTML 빌드 폴더로 복사해 참조한다. 파일이 없으면 이미지 자리를 비우고 레이아웃만 유지한다(깨진 이미지 아이콘이 보이면 안 된다). 이 이미지는 Google 공개 보고서의 표지이므로, 표지 슬라이드 하단의 출처 문구("Google × The Behavioural Architects 「Decoding Decisions」 기반")를 절대 생략하지 않는다.
- 빌드 후 자체 점검: 모든 텍스트가 화면 밖으로 넘치지 않는가, 색이 토큰 5색뿐인가, 푸터가 전 슬라이드에 있는가.
